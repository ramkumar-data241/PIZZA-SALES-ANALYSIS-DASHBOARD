🍕 Pizza Sales Performance Dashboard

Project Overview

This project analyzes pizza sales data using Power BI to understand sales performance, revenue trends, customer ordering patterns, and product performance.

## Dashboard Preview

![Pizza Sales Dashboard](dashboard.png)

Key Performance Indicators (KPIs)

- Total Revenue
- Total Orders
- Average Order Value
- Total Pizzas Sold
- Average Pizzas Per Order

Dashboard Features

Sales Analysis

- Monthly Revenue Trend
- Orders by Day of Week
- Sales Distribution by Pizza Category
- Sales Distribution by Pizza Size
- Total Pizza Sold by Size and Category
- Revenue by Pizza Name

Best & Worst Selling Pizzas

- Top Pizza by Revenue
- Top Pizza by Orders
- Top Pizza by Quantity Sold
- Worst Pizza by Revenue
- Worst Pizza by Orders
- Worst Pizza by Quantity Sold

Tools & Technologies

- Power BI
- Microsoft Excel
- Power Query
- DAX

Key Insights

- Analyzed monthly pizza sales performance.
- Identified top and bottom-performing pizzas.
- Compared revenue across pizza categories.
- Evaluated sales distribution by pizza size.
- Identified ordering trends.
